# Higgsfield source media

journey-master.mp4 is the original provider output from the approved starting plate, preserved without alteration. It is HEVC Main10, 1920 x 1080, 24 fps, 289 frames, BT.709 SDR and silent.

The site plays ../../public/assets/video/journey-higgsfield.mp4, a duration- and timestamp-preserving H.264/yuv420p conversion. The encode uses CRF19, medium preset, GOP6, BT.709 and faststart. Both files fully decoded during review. No generation service is required to build or serve the website.

The eight WebP chapter posters were extracted from the browser encode at frame indices 0, 108, 198 and 282, with 1920 x 1080 and 960 x 540 variants. All of these assets are tracked under public/assets/images.

media-verification.json records the hashes, measured properties and actual reading times. See ../../docs/higgsfield-integration.md for checks and the final-shot deviation. Private account identifiers, credit ledgers and generation prompts are not part of this public asset package.
